This repository contains the implementation for “Cross-Border Electricity Price Forecasting with Deep Learning”, a Bachelor’s thesis project conducted at Karlsruhe Institute of Technology (KIT). The study systematically evaluates multiple deep learning models for day-ahead electricity price forecasting (DAEPF) in the Germany-Luxembourg (DE-LU) bidding zone, leveraging data from 15 European bidding zones.


Data for transfer learning not available due to size limits. But the Crawlers are available to run, which fetches the data by running them in the correct ascending numerical order.
